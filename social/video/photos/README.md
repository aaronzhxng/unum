# Video photo library

Backgrounds and cards for `video.mjs`. Only add photos we are free to use:
public domain, CC0, or our own. Add each new file to `credits.json` (the
credit line that goes in the post caption, or `null` when none is needed).

Highsmith photos of artworks (statues, murals, paintings) can still be under
the artist's copyright, so stick to buildings, rooms and skylines.

Larger copies of any Highsmith photo: `https://tile.loc.gov/image-services/iiif/service:pnp:highsm:<folder>:<number>/full/,2400/0/default.jpg`,
where the folder is the number rounded down to the hundred (`12500:12503`).
